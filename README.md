# 📈 Stock Price Analyzer

Stock Price Analyzer is a Python-based application that downloads historical stock market data and performs basic statistical analysis.

The project calculates the highest price, lowest price, average price, latest price, and daily percentage changes. It also generates a graphical representation of the stock's closing price.

## 🚀 Features

- Download historical stock data
- Analyze stock closing prices
- Calculate highest stock price
- Calculate lowest stock price
- Calculate average stock price
- Display latest stock price
- Calculate daily percentage changes
- Generate stock price graphs
- Automated testbench
- Object-oriented Python implementation

## 🛠️ Technologies Used

- Python
- Pandas
- Matplotlib
- yfinance
- unittest
